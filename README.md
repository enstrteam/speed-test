# Speed Tester

Скрипт для измерения скорости загрузки данных с указанного URL.

## Описание

Программа выполняет последовательные HTTP-запросы к переданному адресу, измеряет:

- время каждого запроса
- общий объем загруженных данных
- среднюю скорость загрузки (MB/s)

## Как работает

1. Пользователь вводит URL
2. Скрипт выполняет 10 запросов к ресурсу
3. Для каждого запроса фиксируется:
   - время выполнения
   - размер ответа в байтах
4. В конце рассчитывается:
   - среднее время запроса
   - общий объем данных
   - скорость загрузки в MB/s

## Запуск

```bash
python main.py
```
