# ⚡ Network Speed Tester

Консольная утилита для измерения и визуализации скорости сетевой загрузки по HTTP с интерактивным интерфейсом на базе библиотеки `rich`.

## Описание

Программа выполняет серию HTTP-запросов к указанному ресурсу, замеряет ключевые сетевые показатели и визуализирует процесс и результаты прямо в терминале:

- ⏳ **Анимированный прогресс-бар** со спиннером и таймером в реальном времени
- 📋 **Таблица детализации запросов**: статус HTTP-ответа, объем загруженных данных, задержка (мс/с) и скорость
- 📊 **Итоговая карточка статистики**:
  - Общий объем данных и суммарное время
  - Средняя задержка (Latency)
  - Средняя, пиковая и минимальная скорость
  - Спарклайн-график динамики скорости (` ▂▃▄▅▆▇█`)
- 🛡 **Безопасная обработка ошибок**: корректная обработка сетевых сбоев, таймаутов и прерывания через `Ctrl+C`

## Установка

1. Клонируйте репозиторий:
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd "speed test"
```

2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # На Linux/macOS
# venv\Scripts\activate   # На Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

При запуске утилита предложит:
- **URL для теста** (по умолчанию используется тестовое изображение, можно нажать `Enter` для быстрого старта);
- **Количество запросов** (по умолчанию `10`).
